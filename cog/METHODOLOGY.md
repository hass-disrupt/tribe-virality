# Virality Score — Methodology, Accuracy & Limitations

This document states plainly what the "Virality Score" is, what it is built on,
where it is scientifically grounded, and where it is **not**. Read it before
treating any score as meaningful.

## 1. What TRIBE actually is (and is not)

TRIBE v2 ([facebook/tribev2](https://huggingface.co/facebook/tribev2),
[arXiv 2605.04326](https://arxiv.org/abs/2605.04326)) is an **encoding model**:
given video/audio/text it predicts the **BOLD fMRI response** of the average
subject on the fsaverage5 cortical mesh (~20,484 vertices).

It is **not** a model of behaviour, preference, engagement, or virality. The
paper is explicit that it *"treats the brain as a passive observer of
naturalistic stimuli; it does not yet model the brain as an active agent
producing behavior."* Group-level zero-shot encoding accuracy is roughly
R ≈ 0.4. The packaged model returns **cortex only** — the paper's subcortical
Harvard–Oxford voxels are **not** exposed via `TribeModel.predict()`.

**The Virality Score is our heuristic on top of TRIBE, not a TRIBE output.**

## 2. How the score is computed

`predict.py` → `scoring.pipeline.score_preds()`:

1. TRIBE → `preds` `(T, 20484)` BOLD predictions on fsaverage5.
2. For each of 5 constructs, mean activation over that construct's atlas
   vertices (`scoring/rois.py` ← `data/roi_mapping.json`).
3. Signed z-score vs a baseline, then logistic sigmoid → 0–100:
   `score = sigmoid(sign · (x − μ) / σ) · 100`.
4. Headline = weighted sum of the five sub-scores (`scoring/constants.py`).
5. Same transform per timestep → `timeline`.

## 3. Scientific grounding

- **ROI → vertices.** The Destrieux (aparc.a2009s) cortical atlas on
  fsaverage5, generated by `data/build_roi_mapping.py` (see `scoring/atlas.py`
  for the construct → parcel table). Disjoint across constructs.
- **Direction.** Per-construct `ROI_SIGN` in `scoring/constants.py`. Anterior
  insula / `emotion` is sign-inverted per Genevsky & Knutson; the others are
  positive heuristic priors.
- **Baseline.** Per-construct mean/std in TRIBE's native output units, used to
  z-score a video's activation. The shipped values are **empirical**, computed
  from a small reference corpus (see `data/baseline_stats.json` provenance).
  Two generators produce them: `data/build_baseline_stats.py` (runs TRIBE
  in-image on local clips) and `data/build_baseline_from_predictions.py` (no
  GPU — recovers activations from saved Replicate prediction JSONs). The corpus
  is small and arbitrary, so this calibrates "typical of these clips," not
  virality — see §4.

### Construct → Destrieux parcels (the documented heuristic)

Defined in `scoring/atlas.py` (`DESTRIEUX_CONSTRUCT_PARCELS`):

- **reward** — orbital gyri/sulci, gyrus rectus, subcallosal, inferior-frontal
  orbital. Cortical proxy for OFC/vmPFC value signal (the best-validated
  forecaster, subcortical NAcc, is not exposed by the model — see §4).
- **emotion** — short/long insular gyri, circular insular sulci, anterior &
  mid-anterior cingulate. **Sign-inverted.**
- **attention** — calcarine/cuneus/occipital + transverse temporal (Heschl /
  planum temporale, auditory) + intraparietal sulcus.
- **novelty** — parahippocampal, anterior collateral transverse sulcus,
  posterior cingulate, pericallosal sulcus.
- **social_relevance** — medial superior frontal (mPFC proxy), frontopolar,
  angular gyrus / posterior STS (TPJ), precuneus, subparietal sulcus.

These are **approximations**: Destrieux has no clean mPFC or TPJ parcel, so
those constructs use the closest available parcels. This is a defensible
literature-informed mapping, not a validated one.

### Directionality (`scoring/constants.py` `ROI_SIGN`)

Genevsky & Knutson, *PNAS* 2020 ("Brain activity forecasts video engagement in
an internet attention market", [PMC7104008](https://pmc.ncbi.nlm.nih.gov/articles/PMC7104008/))
found that, at video onset and at the group level, **increased nucleus
accumbens** and **decreased anterior insula** activity forecast aggregate
engagement. We therefore invert `emotion` (anterior insula / salience):
higher activation lowers the score. `attention`/`novelty`/`social_relevance`
are positive **heuristic priors**, not direct results of that study.

## 4. What is still NOT validated (limitations)

1. **No engagement-labelled validation.** No corpus of videos with real
   view/engagement metrics is available, so the virality mapping itself is
   **unvalidated**. Treat scores as an *experimental relative heuristic*, not a
   calibrated probability of going viral.
2. **Baseline corpus is small and arbitrary.** `data/baseline_stats.json` is
   empirical but computed from only a few dozen generic clips with no
   engagement labels. So absolute scores are calibrated to "typical of that
   corpus," not to virality, and an in-corpus clip is biased toward the middle.
   The σ estimates tighten and cross-video discrimination improves as the
   corpus grows — regenerate with more clips (40–50+) and bump `SCORING_VERSION`.
3. **Vertex ordering is assumed.** The atlas mapping assumes TRIBE's cortical
   output is the standard fsaverage5 order: left hemisphere `[0:10242]` then
   right `[10242:20484]`. This is **not documented** by TRIBE and must be
   verified (see §5) before scores are trustworthy.
4. **Best signal unavailable.** The strongest neuroforecasting predictor (NAcc)
   is subcortical and not exposed by the packaged model; `reward` is a cortical
   OFC/vmPFC proxy for it.
5. **Cognitive constructs are interpretive.** TRIBE predicts BOLD, not "reward"
   or "emotion"; reverse-inference from a region to a cognitive process is a
   known fallacy. Constructs and weights are a transparent heuristic prior.

## 5. Deferred verification (needs cog image + GPU)

Before relying on scores, confirm the vertex-ordering assumption in §4.3:

1. Run a visually dynamic clip through TRIBE; confirm `preds` is `(T, 20484)`.
2. Project the Destrieux atlas; check **calcarine / early-visual** vertices
   are strongly driven and **medial-wall** vertices are near-flat.
3. Confirm the lh/rh split is at index 10242.

If the ordering differs, regenerate `roi_mapping.json` accordingly. Then run
`data/build_baseline_stats.py` (limitation #2) and a face-validity check (a
high-arousal clip should score meaningfully above a static/neutral one — this
is sanity, not ground-truth validation).
